Niriko · UI 升级原型 · 现状 vs 改后

配套计划：docs/ui-upgrade-plan-2026.md。本页只画改动面，不重画整页；未标注的区域表示保持现状。手机框用手机尺寸，平板 / 折叠屏单独给形态。

使用方式：上方 tab 切换批次（B1 图表 / B2 自适应 / B3 日历 / B4 加载态 / B5 玻璃 / B6 回归）。每个对比块左侧是现状、右侧是改后，圆圈里的数字对应右下角图例。

范围提示（已按你的确认更新）：① AniHyou（AniList 层工程化）与 ⑤ Reorderable（长按拖拽自定义排序）已移出，本页不含这两项，也不含任何数据库迁移。
标注含义：橙色数字 = 本次改动点；灰色「保持现状」 = 明确不改的区域。扁平圆角标记（采纳/否决/待确认）分别表示已定、已排除、需你拍板。
实现前提：本页是形态稿，不是最终视觉稿；配色取自项目现有 ChartPalette / 玻璃令牌，最终以真机截图基线（B6）为准。

复用而非重写LiquidBottomTabs.kt 的 drawBackdrop 链（vibrancy + blur(8dp) + lens(24dp)）、DampedDragAnimation、InteractiveHighlight 与「选中项 56dp 玻璃片 + 色散」三层结构整体沿用，只把 x 方向的手势与测量换成 y 方向。

色散方向透镜 shader 的色散项是 x·y/(hx·hy)（四叶反对称，两条中轴上恒为 0）→ 竖排 dock 的彩虹落在短边（即底栏的 90° 旋转结果），长边保持干净。这是固定行为，不需要改 shader。
需要调参gradRadius = min(radius×1.5, min(halfSize.x, halfSize.y)) —— 竖排 dock 的窄边会把透镜半径钳到 ~36dp，等效于「整条 dock 都在折射」。LiquidGlassConfig 需新增 VerticalDock 预设（比 40dp 更小的 cornerRadius、更克制的 refractionHeight / dispersion），这属于 B5 的调参范围。
收起行为可复用已确认项目存在 bottomBarHideFraction（滚动隐藏，当前位移 8dp + 透明度 0.15）—— 竖排 dock 可复用同一 trait，收起方向改为向左滑出。
顺带：海报网格列数按宽度类别取 2 / 3 / 4~6（现为固定值）；筛选条在宽屏下不再横向滚动；设置页「分类导航 + 二级内容」并排。
断点：<600dp 手机（现状）· 600~839dp 小平板 / 折叠屏折叠（网格 +1 列，底栏保留）· ≥840dp 平板 / 折叠屏展开（竖向 dock）。
已否决的替代：贴边满高 NavigationRail（Material 默认观感，与现有玻璃语言不一致，且 NavigationSuiteScaffold 承载不了跟手动画）—— 见下方对比稿。

可删预计删除约 300 行手写布局（MonthHeader / WeekdayHeader / DayGrid）。
待确认 Q2用纯 Android 的 compose 还是 KMP 的 compose-multiplatform 变体（为 docs/ios-port/ 铺路）—— 建议后者，避免二次返工。

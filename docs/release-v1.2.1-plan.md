## 2. 专项：悬浮控件自动显隐（S1）

### 2.1 阶段一：控件清单（只读分析，先确认再改）

| 控件 | 文件 | 现状 | 是否纳入 |
| --- | --- | --- | --- |
| 底部悬浮 Dock | navigation/NirikoBottomBar.kt + ui/bottombar/ | 悬浮胶囊，随 pager 联动 | **是**（向下滚隐藏、向上滚恢复） |
| 作品库左上分区按钮 | ui/library/FolderNavBar.kt | 悬浮，含分区名切换动画 | **是**（按实际位置选退出方向） |
| 发现页左上/右上按钮 | ui/screens/Screens.kt 与 UniversalSearchBar | 悬浮，与作品库各一套 | **是**；且先按 U13 做一体化 |
| 详情页加入收藏 | ui/subject/SubjectDetailScreen.kt | 普通按钮（U18 要改悬浮） | **是**（改悬浮后纳入同一状态） |
| 搜索展开层 / 设置条目 / 卡片内按钮 | — | 非悬浮 | **否**（明确排除） |

### 2.2 规则（从你的 spec 提炼，可直接当验收）

1. **向下滚 → 隐藏**：Dock 向下滑出；上方按钮按各自位置退出；同一页控件协调显隐，不允许 Dock 藏了按钮还挡着。
2. **向上滚 → 恢复**：不要求回到顶部；恢复时尺寸/材质/位置零变化；多滚动容器不重复触发。
3. **点空白 → 恢复**：在页面容器处理点击，不得用全屏透明层；不得拦截卡片点击/长按/搜索/筛选/弹窗。
4. **状态**：首开默认显示；切 Tab / 返回 / 换内容类型不得跳动；旧页面滚动状态不影响新页。
5. **动画**：位移为主，180–250ms，减速或轻弹簧；不得导致列表重排。
6. **系统区**：正确处理导航栏 insets，隐藏后不留残影、不进入手势区；隐藏态不拦截触摸。

### 2.3 硬性红线（你的原话）

只改显隐相关文件；不重构导航；不改 Dock 顺序/路由/尺寸/颜色/点击；不改卡片布局、搜索、筛选、排序、数据源；不新增依赖；不动数据层；关键操作按钮若要隐藏必须先单独说明。

### 2.4 阶段二 / 三

- **阶段二**：先做滚动方向判断纯函数（阈值过滤 + 反向判定，可单测），再接 Dock，最后接页面按钮；空白点击恢复只加在页面容器的空白区域。
- **阶段三**：编译 debug → 逐条跑你的验收清单（滚动方向、恢复、空白点击、动画方向、卡片手势、页面切换、隐藏后触摸穿透）→ 输出改动文件与未解决项。

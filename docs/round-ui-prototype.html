Niriko 本轮 UI 改动原型

按 v1.2.1 最终范围制作：7 处修复 + 27 项新功能中所有会改变界面的点（已剔除空结果引导与首启选线路）。深色主题、360×720 手机框、纯 CSS 模拟；页面底部有逐条标注。此文件与 discover-poster-prototype.html 同一套制作方式。

  1. 统计页顶部：今晚看什么 / 未来七天 / 漏看
  2. 统计页：收藏健康度
  3. 统计页：对比文案 + 口径说明
  4. 统计页日历：导出 / 停播 / 延期 / 时区
  5. 详情页：标题 logo
  6. 详情页：区块折叠 + 分享入口
  7. 发现页：榜单箭头
  8. 设置：新增入口一览 + 设置搜索
  9. 设置：数据体检
  10. 设置：本地快照
  11. 设置：同步预览与演练
  12. 设置：图片占用清理
  13. 关于：检查更新
  14. 分享：分区海报 / 周报卡 / 评分对照卡
  15. 系统：英文界面 / 报错复制

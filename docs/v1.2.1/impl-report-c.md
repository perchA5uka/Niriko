## 2. 集成时抓到并修掉的 4 个真问题

1. **Kotlin 嵌套注释**：KDoc 里写路径 `files/snapshots/*.json.gz`，其中 `/*` 开启了嵌套注释，把整个文件吞掉（编译器报 `Unclosed comment`）。改为不含 `/*` 的表述。
2. **Sequence.flatMap 里读 Room**：`getMainEpisodes` 是 suspend，而 `flatMap` 的 lambda 不是 suspend；改成普通 `for` 循环（上限 200 部）。
3. **DAO 新增计数导致测试替身编译失败**：`CollectionDao` 加 3 个 `COUNT` 后，两处 `FakeCollectionDao` 必须实现；已补。
4. **`rankMap` 没丢非法 subjectId**：`-1` 是占位脏数据，测试期望丢弃；实现补 `filterKeys { it > 0 }`。

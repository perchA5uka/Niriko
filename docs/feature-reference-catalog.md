# Niriko 功能缺口参考清单

> **v2 已出**：`docs/feature-reference-catalog-v2.md`（源码级证据版，36 个参考仓库 + 248 条明细 + 12 处勘误 + 10 条跨域新功能）。本文保留为**功能清单与取舍**的基线，未被 v2 替代。

> **这是一份独立的清单文档**，不改动、不替代 `docs/reference-repos-plan.md` 与其余任何方案文件。
> 目的：只列出 Niriko **尚无**或**已实现但不完善**的功能（可参考外部仓库的做法），作为补完与取舍的检查表。
>
> **已完整实现的功能已从本清单删除**（共 57 条：五态模型、单集进度、卷/话双进度、游玩时长、音乐曲目、分集评分、二刷、看这里、批量操作、评分区间、Bangumi OAuth 双向同步、WebDAV 同步、JSON 备份、B 站/Steam/Kazumi 导入、共享元素转场、连续顶部渐隐、图片查看器等）。逐条名称与删除原因见「附录 C · 已删除条目」。
>
> 与 `reference-repos-plan.md` 的分工：那一篇讲**工程实现**（数据源抽象、刷新编排、玻璃降级、移植分层），本篇讲**功能面**。
>
> **可信度**：本机无法直连 github.com，外部仓库的功能描述来自其 README / 官方文档 / Release Notes 的检索快照，未逐行读源码；标「待核」的条目请先在仓库内确认。本项目一侧的「现状」由 `README.md` 与实读代码共同判定。
>
> 级别：**采纳** = 与本项目定位/约定一致，建议排入计划；**视情况** = 有价值但需先定产品取舍。级别的分域计数见 0.1 的汇总表。
> 「缺在哪」的三种形态：**无** = 完全没有；**部分** = 能力在但形态或覆盖面不足；**待核** = 代码中尚未确认，需先查。

- 修复设置主页底部没有为悬浮 dock 预留高度：新分组最后一行会被胶囊压住；现在底部留白 120dp 并叠加系统导航栏 inset，与发现/统计信息流同款。
- 详情返回按导航记录恢复单/双栏浏览位置；关联、猜你喜欢、角色与人员横滑轨道分别保存偏移。共享键在目标首帧作为路由参数可用，头像源卡片预览保障进入端点，不再只有退出有动画。

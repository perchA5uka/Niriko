## 一句话总结

从 258 条候选里，**保留 34 条**：**7 条是修复**（数字算错、进度会丢、时间差一小时），**27 条是新功能**。这 27 条里没有一个需要服务器，也不改变你现在的主流程——只是让几个页面多一两处顺手的东西，以及多一个「详情页显示作品原版 logo」的观感提升。

## 一、先修的 7 件（你已经同意）

| 你会遇到的现象 | 现在的真实原因 | 修好之后 |
| --- | --- | --- |
| 统计里的「总观看集数」数字大得离谱 | 玩游戏的时长被当成「集数」加进去了 | 游戏单独算小时，动画单独算集数，各归各的 |
| 放送时间比实际早/晚一小时 | 时间被写死成北京时间，没按你的时区换算 | 按你手机的时区显示，日历导出也一致 |
| 换了手机，「看到第几卷」没了 | 卷进度没有被放进同步和备份 | 卷进度跟着一起走 |
| 两台设备同步后，一边的改动不见了 | 上传前不检查远端有没有更新的内容，直接盖 | 发现冲突会停下来问你要保留哪边 |
| 设置里调好的数据源顺序，重开 App 又变回去 | 顺序没有被记住 | 记住，重启也在 |
| 在地铁里标的进度，回家要手动点一次全量同步才上去 | 没有「待办箱」：离线写的东西不会自己补交 | 联网自动补交，失败的会进「待补交」列表，看得见 |
| 列表滚进来的动画是一起蹦出来的 | 「错峰」写了但没生效 | 一个一个来，有节奏 |

> 这 7 件事都属于「修」而不是「加」，不改变任何操作习惯，只是让数字和进度变对。

## 二、确定要加的功能（按屏幕）

### 1. 作品库

**本轮不新增。** 这一页只等那 7 个修复（尤其是进度与同步相关的），不加新按钮。以后若要再加，会从「修完之后还真的缺什么」重新评估，不在本轮清单里。

### 2. 发现页

| 新增 | 你会看到 | 什么时候有用 |
| --- | --- | --- |
| 榜单变化 | 详情页的榜单成绩旁，**主题色的 ↑ / ↓ 箭头 + 数字**（例如 `↑ 12`），不写「上升 12 位」这类文字 | 一眼看出它最近在涨还是在跌 |

> 榜单变化的表现形式已按你的要求改：**只用箭头和数字，颜色跟主题走**；涨用向上箭头，跌用向下箭头，持平不显示。你的原话「空结果引导也不要」——本轮已撤下，保持现状。

### 3. 作品详情页

| 新增 | 你会看到 | 什么时候有用 |
| --- | --- | --- |
| 标题显示作品原版 logo | 现在的纯文字标题，换成作品原版 logo（日文/中文）；没有 logo 的条目仍然显示文字；设置里三档「关 / 始终 / 看不清时显示文字」，默认关 | 一眼认出作品，详情页更有「作品感」 |
| 区块可收起 | Steam / VNDB / AniList 这些区块能折叠 | 只想看评分和剧集时页面更短 |
| 评分对照卡 | 分享一张「我 9 分｜全站 7.2 分」的图 | 想发群里吐槽或安利 |

> 「标题 logo」是新增的一条（来自 `izuko-tv` 的那份计划）。它数据层几乎现成，是本轮**唯一**的「观感级」改动；如果你不想要，划掉即可，不影响其他条目。

### 4. 统计页（日历就在这一页上）

> **先说明**：Niriko 没有独立的「日历页」，日历是统计页里的一个区块。下面所有日历相关的改动，都在统计页内完成，不会新增一个 Tab。

| 新增 | 你会看到 | 什么时候有用 |
| --- | --- | --- |
| 今晚看什么 | 统计页第一张卡：「今天 4 部更新，其中 2 部你在看」 | 打开就知道今晚看什么 |
| 接下来七天 | 一行 7 格，每格放当天更新的封面 | 提前安排周末 |
| 漏看提醒 | 「《某作品》落后 3 集」 | 比「有新集了」更有用 |
| 收藏健康度 | 四个数字：停滞的、没评分的、没标签的、空分区；点进去就是筛好的列表 | 清理收藏不再是体力活 |
| 一句话对比 | 「比上月多看了 7 部」 | 数字变成人话 |
| 口径说明 | 完成率旁边的问号：「分母含不含『抛弃』」 | 不再怀疑数字怎么算的 |
| 导出到系统日历 | 一键生成日历文件，手机自带日历里能看到放送 | 不用开着 Niriko 也知道今晚几点 |
| 时区正确 | 按你手机时区显示，导出的日历也一致 | 出国/换时区不再错一小时 |
| 停播 / 延期角标 | 停播那一周标出来，延期标「延期」 | 不再白等 |

> **「统计跟着筛选走」已去掉**——你说得对，统计页本来就没有筛选，那条是把别的页面的概念套过来了，作废。

### 5. 设置

| 新增 | 你会看到 | 什么时候有用 |
| --- | --- | --- |
| 同步「预览 + 演练」 | 同步前先看差异（本地：看过 8 分 / 远端：在看），逐条勾方向，再「演练」一遍看将要发什么，最后才执行 | 以前点一下就把数据改了，现在能反悔 |
| 数据体检 | 「检查我的数据」：8 项检查（重复条目、孤儿绑定、坏封面、缓存太大…），可一键修 | 感觉哪里不对但说不清 |
| 本地快照 / 回滚 | 同步前自动存一份，「最近 5 份」，可以回到 10 分钟前 | 误操作有后悔药 |
| 玻璃效果自动档 | 按手机性能自动选效果，不用自己一档档试 | 老手机不再卡 |
| 图片占用与清理 | 「占用 2.1GB：封面 180MB / 剧照 1.2GB / 壁纸 700MB」，每项可清 | 手机存储告急 |
| 数据源自检 | 一眼看到哪条线路挂了、最近错误是什么 | 搜不到东西时不用猜 |
| 深色对比度 | 深色模式下文字更清楚 | 夜里看 |
| 应用内更新 | 「关于」页的「检查更新」：有新版本时提示并给一个「去下载」，点开浏览器到 Releases 页面 | 不用自己记着去翻 Releases |

### 6. 桌面与系统

| 新增 | 你会看到 | 什么时候有用 |

## 六、最值得期待的 5 件事

1. **数字终于对了** —— 游戏时长不再混进集数，换时区不再差一小时。
2. **今晚看什么** —— 打开统计页第一张卡就是答案，不用翻日历。
3. **详情页显示作品原版 logo** —— 一行黑体字变成作品自己的字标。
4. **同步可以演练** —— 先看会发生什么、逐条勾方向，再执行；配上本地快照，误操作能退回十分钟前。
5. **数据体检** —— 「我的收藏是不是坏了」终于有地方查，而且能一键修。

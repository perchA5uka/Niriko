Niriko v1.2.2 · 待确认的外观改动原型

已实施（v1.2.2，2026-10-31，A 方案）：① 分段 → NirikoSegmentedControl（Pill + 主色 20% 淡底 + 1dp 描边 + 等宽 13sp + 48dp 行高）；② chip → NirikoTagPill / NirikoFilterPill / NirikoSelectionPill / NirikoActionPill；③ 菜单 → NirikoMenu + GlassMenuOverlay（24dp 玻璃 + 锚点缩放 + 退场 + Back/Esc）；④ 统计数字 → StatNumber / StatLabel / StatNote / StatTile。本页保留为历史设计对照，实现状态见 impl-summary.md §6.11。

前七批（设置页对齐 / 详情页破相 / 反馈宿主 / 多选 / 动效 / 形状令牌 / reduceMotion）已经写进 APK，可直接在 dist/niriko-v1.2.2-debug.apk 里试。

这一份只画 还没动、且会改变控件外观的 4 项——它们不在已批准的 D1–D4 里，需要你先确认方向再动代码。每节左边是「现状」（按 v1.2.1 截图复刻），右边是「提案」，下方红框是需要你拍板的选项。

  1. ① 分段选择器统一（V-11）
  2. ② chip 五副面孔收敛（V-12）
  3. ③ 锚定菜单统一（V-14）
  4. ④ 统计数字三档（V-21）

① 分段选择器统一（V-11）

现状：全站 4 套分段并存——详情页「观看状态」是深底 + 实心绿胶囊（12sp 硬编码文字），统计页是玻璃容器 + 实心绿胶囊（宽度随文案不等），设置页/搜索筛选又是别的形态；而写好的 GlassSegmentedContainer 至今 0 个调用点。提案把它变成唯一实现：玻璃容器 + 主色淡底 + 主色描边，文字 13sp、等宽分段。
